# 剪影生成器 v1.2.1｜使用说明

作者：安鱼 · [创意网站](https://www.anyusj.com/) · [小红书](https://xhslink.cn/m/5g1EQhRumkz)。用于摄影剪影和独立海报拼贴，照片在浏览器本地处理，不上传服务器。当前以桌面电脑为主，手机专门交互未完成。

## 安装和打开

最简单的方式：下载 Releases 中的桌面本地工具包 ZIP，完整解压，把 AGENT-INSTALL.md 或下述一句话交给你的 AI Agent：

> 请完整安装这个剪影生成器工具包，按照 AGENT-INSTALL.md 启动本地网页并验证上传照片和 PNG 导出，不要部署公网，不要上传我的照片。

Windows 双击 START-WINDOWS.cmd；Mac / Linux 使用对应 START 文件（首次可能需要 Agent 设置执行权限）。成功后黑框/启动终端可自动退出，不要反复强行关闭后台进程。停止用 STOP-*。需已安装 Node.js 或 Python；运行时缺少时 Agent 会按它自身的授权规则帮助安装，不保证所有 Agent 都能绕过系统权限。

不要双击 app/index.html。浏览器使用 http://127.0.0.1:4173/ 或启动器实际显示的地址；端口占用时会顺延。没有照片云上传，没有服务器收费或 WordPress 配置。

## 从一张照片开始

1. 点击“上传照片”或把 JPG / PNG / WebP 拖入画布。模型加载和处理有状态提示，大图会稍慢；失败可用 CPU 兼容重试。
2. 新照片默认“原图挖空”：背景里的主体透明挖空，纯色剪影覆盖原位置；实体主体放在另一块纯色区域。原图保持彩色，不自动变黑白。蒙版内部为实心，抠漏细节可修正。
3. 选择上下、左右、剪影覆盖或残影布局；上下/左右有“对调分区”按钮，连背景和对应对象整组换位置，不镜像内容。比例数值代表剪影背景区域占比。
4. 画布提供多种比例及自定义 320–6000 px 尺寸，可锁定宽高比；“适应窗口”只改变预览，不改变导出尺寸。

## 图层与变换

四个基础图层为纯色剪影、实体主体、纯色背景、剪影背景。列表越上越靠前，拖动图层改变叠加顺序，预览和 PSD 同步。点击画面可选中实际可见对象；变换框能直接移动、等比缩放和旋转，也能用统一位置/大小滑钮。

主体和剪影可跨分区叠加。背景仍裁切在自己的分区内，变换框可以超过画布，但导出不含画布外内容。纯色分区大小使用区域比例调整，不作为可随意旋转的图片对象。

## 背景、颜色和阴影

- 剪影背景可选“原图挖空”“图片背景”“纯色背景”。图片背景内置九张，也支持上传本地图片、按原照片色彩匹配；上传背景可单独移动、缩放和旋转。切换回新照片时再次默认原图挖空。
- 原图挖空模式可以同步原图背景和剪影的变换，或重新对齐。图片/纯色模式不依赖原图背景，不生成主体形状的透明洞。
- 剪影颜色有五个根据照片推荐的色彩和自定义颜色。内阴影、外阴影、柔化范围可连续调节；内阴影只作用于轮廓内边缘。
- 表面质感默认无，可开启纸纹或颗粒，选择“无”关闭。

## 半调、像素和散落文字

选中实体主体，在“实体主体效果”开启彩色半调。圆点、方块、菱形、椭圆、线条可选；网点大小、角度、混合、锐度可调。混合 0 为原照片，100 为纯网点，间隙显示下层背景。

选中纯色剪影，可选实心/像素轮廓并调整像素大小。散落文字是独立开关，可自定义中英文内容、密度、字号、颜色，或换一套排列；只散落在轮廓内部，不是额外的自由文字图层。效果默认关闭，关闭后恢复普通主体/剪影。

散落字号可调 30–600，按照片长边等比例计算，不受像素格大小限制。放大剪影或提高导出尺寸时文字同步放大；大字号会自动留出更宽的间距，避免文字拥挤。

## 自由涂抹

选中实体主体或纯色剪影，开启自由涂抹或橡皮。画笔取回源照片像素，橡皮删除区域，两种表示共享轮廓。笔刷及橡皮默认 6，最小 1，光标圆圈表示范围。透明蒙版模式便于看清边缘。

支持最多 15 步撤销/重做（受历史内存预算限制）、Ctrl / ⌘ Z、Ctrl / ⌘ Shift Z；[ ] 调整笔刷。改阈值并重新应用实心轮廓会清除手动修改。效果启用时先修正基础蒙版，再重新计算半调或像素效果。

## 导出

PNG / JPG / WebP 有 1×、2×、4×；大尺寸受像素/内存预算限制，以面板实际显示值为准。导出从原图和对象重新渲染，不含 UI。透明剪影 PNG 单独输出轮廓。PSD 在电脑端输出四个独立栅格图层，开启表面质感时可能增加质感层；文字和半调落在对象栅格中，不是 Photoshop 可编辑文字层或智能滤镜。

导出下载文件由浏览器保存。某些浏览器会询问是否允许多个下载。若 PSD 提示动态模块失效，请刷新当前页面重试。PSD 画布限制 1200 万像素以控制图层内存。

## 限制与兼容性

推荐新版桌面 Chrome / Edge。Windows Chrome 实际测试过自动抠图、离线模型、图层、效果、分区对调、笔刷和导出；Mac/Linux 启动脚本和浏览器兼容代码已提供，但不代表已测试所有系统或 Safari/Firefox 所有版本。显卡或 Worker 不可用时有 CPU/WASM 兼容路径。

细小手指、发丝、重叠和多人独立分割可能仍需手工修正；多人目前使用一张组合蒙版。大网点和粗像素会简化细节。不同系统字体可能让散落字形略有不同。项目不保存可恢复的完整编辑工程文件，也不承诺绝对准确抠图。
